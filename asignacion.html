MODELO DE ASIGNACIÓN

¿Qué es el Modelo de Asignación?

El Modelo de Asignación es un modelo de Investigación de Operaciones utilizado para asignar recursos a diferentes actividades de la manera más conveniente.

Por ejemplo, puede utilizarse para asignar:

-Trabajadores a trabajos.

-Máquinas a tareas.

-Conductores a vehículos.

-Vendedores a zonas.

-Profesores a cursos.

El objetivo normalmente es minimizar costos o tiempos, aunque también puede utilizarse para maximizar beneficios.

Objetivo del Modelo de Asignación

Su objetivo es encontrar la combinación de asignaciones que produzca el mejor resultado posible.

Puede buscar:

-Menor costo.

-Menor tiempo.

-Menor distancia.

-Mayor productividad.

-Mayor beneficio.

Método Húngaro

Uno de los métodos más utilizados para solucionar el Modelo de Asignación es el Método Húngaro.

De forma general, sus pasos son:

Buscar el número menor de cada fila.

Restarlo a todos los números de esa fila.

Buscar el número menor de cada columna.

Restarlo a todos los números de esa columna.

Analizar los ceros obtenidos.

Seleccionar los ceros de manera que cada trabajador tenga una sola tarea.

Realizar nuevas reducciones si todavía no es posible completar las asignaciones.

Aplicaciones del Modelo de Asignación

El Modelo de Asignación puede utilizarse para:

-Asignar empleados a puestos.

-Asignar máquinas a trabajos.

-Asignar profesores a cursos.

-Asignar vehículos a rutas.

-Asignar vendedores a regiones.

-Asignar técnicos a reparaciones.

-Asignar proyectos a equipos de trabajo.

Diferencia entre Modelo de Transporte y Modelo de Asignación

Modelo de Transporte:

- Distribuye cantidades

- Puede enviar varias unidades

- Utiliza oferta y demanda

- Busca rutas de distribución

- Puede tener diferentes cantidades

Modelo de Asignación

- Asigna recursos

- Normalmente asigna una unidad

- Utiliza trabajadores y tareas

- Busca la mejor combinación

- Cada recurso suele recibir una sola tarea

El modelo de asignación puede considerarse un caso especial del Modelo de Transporte en el cual las ofertas y demandas normalmente tienen el valor de una unidad.
