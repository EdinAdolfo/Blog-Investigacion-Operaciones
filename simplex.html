¿Qué es el Método Simplex?

El Método Simplex resuelve un modelo de Programación Lineal mediante iteraciones algebraicas. En cada iteración se pasa de una solución básica factible a otra que mejora o conserva el valor de la función objetivo, hasta alcanzar una solución óptima.

El método fue creado por George B. Dantzig en 1947 y resulta especialmente útil cuando el problema tiene más de dos variables, pues en esos casos el Método Gráfico deja de ser práctico. Su operación principal es el pivoteo, que emplea operaciones elementales de fila para modificar las variables que integran la base.

Elementos importantes del Método Simplex.

Para utilizar correctamente el Método Simplex se deben identificar los siguientes elementos:

• Forma estándar. Las restricciones se transforman en ecuaciones y los términos independientes deben ser no negativos.

• Variables de holgura. Se incorporan a las restricciones de tipo menor o igual para representar el recurso que queda sin utilizar.

• Tabla inicial. Reúne los coeficientes de la función objetivo, las restricciones, las variables básicas y los valores del lado derecho.

• Variable entrante. Es la variable no básica que puede mejorar en mayor grado el valor de la función objetivo.

• Variable saliente. Es la variable básica que debe dejar la base para mantener la factibilidad.

• Elemento pivote. Es el número situado en la intersección de la columna entrante y la fila saliente.

• Operaciones de fila. Transforman el pivote en uno y los demás valores de su columna en cero.

• Criterio de optimalidad. En un problema de maximización con la fila Cj - Zj, se alcanza el óptimo cuando no quedan valores positivos.

¿Cómo se aplica el Método Simplex?

Para resolver un problema de maximización pueden seguirse estos pasos:

1. Formular el modelo. Definir las variables de decisión, la función objetivo, las restricciones y las condiciones de no negatividad.

2. Convertir el modelo a su forma estándar. Añadir una variable de holgura a cada restricción de tipo menor o igual.

3. Construir la tabla inicial. Incluir los coeficientes de todas las variables y tomar las variables de holgura como base inicial.

4. Calcular Cj - Zj. Localizar la columna con el valor positivo más alto; esa será la variable entrante.

5. Aplicar la prueba de la razón mínima. Dividir cada valor positivo de b entre el coeficiente positivo de la columna entrante. La razón menor determina la variable saliente.

6. Elegir el pivote. Utilizar el elemento que está en la intersección de la columna entrante y la fila saliente.

7. Realizar operaciones de fila. Dividir la fila pivote por el pivote y convertir en ceros los demás valores de esa columna.

8. Repetir el procedimiento. Construir otra tabla y recalcular Cj - Zj mientras haya algún valor positivo.

9. Interpretar la solución. Leer los valores de las variables básicas y reemplazarlos en la función objetivo.

Ejemplo práctico

Una empresa elabora dos tipos de lámparas: lámparas de mesa y lámparas de pie.

Cada lámpara de mesa produce Q30 de utilidad y requiere 2 horas de ensamblaje y 1 hora de cableado.

Cada lámpara de pie produce Q50 de utilidad y requiere 3 horas de ensamblaje y 2 horas de cableado.

La empresa cuenta con 8 horas de ensamblaje y 5 horas de cableado por jornada. Se busca determinar cuántas lámparas de cada tipo deben fabricarse para obtener la mayor utilidad.

Paso 1: Variables

X1 = cantidad de lámparas de mesa

X2 = cantidad de lámparas de pie

Paso 2: Función objetivo

Dado que se busca maximizar la utilidad:

Max Z = 30X1 + 50X2

Paso 3: Restricción de ensamblaje

2X1 + 3X2 <= 8

Paso 4: Restricción de cableado

X1 + 2X2 <= 5

Paso 5: No negatividad

X1, X2 >= 0

Modelo completo

Max Z = 30X1 + 50X2

Sujeto a:

2X1 + 3X2 <= 8 X1 + 2X2 <= 5

X1, X2 >= 0

Resolución paso a paso

Paso 1: Convertir a forma estándar

Se incorporan las variables de holgura S1 y S2 para transformar las desigualdades en ecuaciones:

2X1 + 3X2 + S1 = 8

X1 + 2X2 + S2 = 5

Paso 2: Construir la tabla inicial

Los coeficientes de la función objetivo son Cj = 30, 50, 0, 0.

BaseCbX1X2S1S2bRazón
S10231088/3 = 2.67
S20120155/2 = 2.50
Cj - Zj 305000

Como 50 es el valor positivo más alto de Cj - Zj, X2 es la variable entrante. La razón positiva menor es 2.50; por ello, S2 es la variable saliente. El elemento pivote es 2.

Paso 3: Primera iteración

La segunda fila se divide entre 2 para transformar el pivote en uno:

F2 nueva = F2 / 2

Luego se elimina X2 de la primera fila:

F1 nueva = F1 - 3(F2 nueva)

BaseCbX1X2S1S2bRazón
S100.501-1.50.50.5/0.5 = 1
X2500.5100.52.52.5/0.5 = 5
Cj - Zj 500-25

Aún hay un valor positivo en Cj - Zj. Por tanto, X1 entra a la base. La razón positiva menor es 1, de modo que S1 sale de la base. El nuevo pivote es 0.5.

Paso 4: Segunda iteración

F1 nueva = F1 / 0.5

F2 nueva = F2 - 0.5(F1 nueva)

BaseCbX1X2S1S2b
X130102-31
X25001-122
Cj - Zj 00-10-10

Paso 5: Solución óptima

En la tabla final ya no hay valores positivos en la fila Cj - Zj. Por consiguiente, la solución es óptima.

X1 = 1 lámpara de mesa

X2 = 2 lámparas de pie

Z = 30(1) + 50(2) = Q130

La empresa debe fabricar 1 lámpara de mesa y 2 lámparas de pie en cada jornada. Esta combinación utiliza las 8 horas de ensamblaje y las 5 horas de cableado disponibles, y genera una utilidad máxima de Q130.

Este resultado evidencia cómo el Método Simplex modifica la base de la tabla mediante pivoteos sucesivos. Cada iteración mejora la función objetivo sin incumplir las restricciones, hasta que no queda una variable que pueda incrementar la utilidad.
