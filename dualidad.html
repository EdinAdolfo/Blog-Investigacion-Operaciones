Dualidad y Análisis de Sensibilidad

1. Dualidad en programación lineal

¿Qué es la dualidad?

La dualidad es una propiedad de la programación lineal que establece que a cada problema original, llamado problema primal, se le puede asociar otro problema denominado problema dual.

Ambos problemas están relacionados matemáticamente y permiten analizar una misma situación desde dos perspectivas diferentes.

Por ejemplo:

El problema primal puede buscar maximizar las ganancias de una empresa.

El problema dual puede buscar minimizar el valor de los recursos necesarios para alcanzar ese resultado.

Cuando ambos problemas tienen soluciones óptimas finitas, sus valores óptimos de la función objetivo son iguales.

Conceptos importantes

ConceptoDefinición
Problema primalModelo de programación lineal original.
Problema dualModelo asociado que se construye a partir del primal.
Variables primalesVariables de decisión del problema original.
Variables dualesVariables asociadas a las restricciones del primal.
Precio sombraValor marginal de una unidad adicional de un recurso, dentro de un rango válido.

Características de la dualidad

Las principales características son:

Todo problema de programación lineal tiene un problema dual asociado.

El número de variables del dual es igual al número de restricciones del primal.

El número de restricciones del dual es igual al número de variables del primal.

Los coeficientes de la función objetivo del primal se convierten en los términos independientes de las restricciones del dual.

Los términos independientes de las restricciones del primal se convierten en los coeficientes de la función objetivo del dual.

El problema dual de un problema de maximización, bajo la forma estándar habitual, es de minimización.

2. Problema primal y problema dual

¿Qué es el problema primal?

Es el problema original que se formula para representar una situación real.

Generalmente contiene:

Variables de decisión.

Una función objetivo.

Restricciones.

Condiciones de no negatividad.

Ejemplo: una empresa quiere determinar cuántas unidades de dos productos fabricar para maximizar sus ganancias, considerando que dispone de recursos limitados.

¿Qué es el problema dual?

Es el modelo matemático que se obtiene a partir del problema primal.

En lugar de enfocarse directamente en las cantidades que se deben producir, puede analizar el valor de los recursos utilizados para alcanzar el objetivo.

La solución óptima del dual está relacionada con la solución óptima del primal y permite interpretar económicamente los recursos disponibles.

3. Reglas para construir el problema dual

Para construir el dual de un problema de maximización con restricciones del tipo menor o igual y variables no negativas, se siguen estas reglas:

Problema primalProblema dual
MaximizaciónMinimización
Variables x1,x2,…Restricciones duales
Restricciones del primalVariables duales
Coeficientes de la función objetivoLado derecho de las restricciones duales
Lado derecho de las restriccionesCoeficientes de la función objetivo dual
Matriz de coeficientes AMatriz transpuesta A^T

4. Teoremas de la dualidad

Dualidad débil

Establece que, para un problema primal de maximización y su dual de minimización, el valor de cualquier solución factible del primal no puede superar el valor de cualquier solución factible del dual.

En términos sencillos:

Esto se cumple cuando ambos problemas están formulados correctamente y las soluciones consideradas son factibles.

Dualidad fuerte

Establece que, si ambos problemas tienen soluciones óptimas finitas, los valores de sus funciones objetivo son iguales.

Zprimal = Zdual

Esto significa que se puede verificar la solución óptima de un problema mediante la solución del otro.

Holgura complementaria

Este principio relaciona las variables del primal con las restricciones del dual.

En términos sencillos:

Si una restricción del primal tiene holgura positiva, la variable dual correspondiente es cero.

Si una variable primal es positiva, la restricción dual correspondiente se cumple con igualdad.

Estas relaciones ayudan a comprobar si las soluciones primal y dual son óptimas.

5. Análisis de sensibilidad

¿Qué es el análisis de sensibilidad?

El análisis de sensibilidad es una técnica que permite estudiar cómo afectan los cambios en los parámetros de un modelo de programación lineal a su solución óptima.

En lugar de resolver nuevamente todo el problema cada vez que cambia un dato, se analiza si la solución actual sigue siendo válida y cómo puede variar el valor de la función objetivo.

Se utiliza principalmente para estudiar cambios en:

Los coeficientes de la función objetivo.

Los recursos disponibles.

Los términos independientes de las restricciones.

Los precios sombra y los costos reducidos.

Objetivos del análisis de sensibilidad

Determinar cómo afectan los cambios en los recursos disponibles a las ganancias o costos.

Identificar cuánto puede variar un coeficiente sin que cambie la base óptima.

Evaluar el valor económico de disponer de recursos adicionales.

Identificar restricciones que limitan la producción o el rendimiento.

Facilitar la toma de decisiones ante cambios en las condiciones de operación.

6. Elementos del análisis de sensibilidad

Precio sombra

El precio sombra representa el cambio marginal en el valor óptimo de la función objetivo cuando se aumenta en una unidad el lado derecho de una restricción, manteniendo los demás parámetros constantes y dentro del rango válido.

Por ejemplo:

Si el precio sombra de una restricción es 0.75, significa que una unidad adicional del recurso puede aumentar la ganancia óptima en 0.75 unidades monetarias.

Este valor es válido dentro del intervalo permitido de variación del recurso.

Costo reducido

El costo reducido indica cómo se relaciona una variable que no está en la solución básica con la posibilidad de mejorar la función objetivo.

En un problema de maximización, una variable no básica con costo reducido negativo no puede mejorar directamente el valor objetivo al aumentar desde cero, manteniendo la base actual.

Cuando una variable de decisión es positiva en una solución óptima, su costo reducido es cero, bajo las condiciones habituales del método Simplex.

Aumento y disminución permisibles

Son los límites que indican cuánto puede aumentar o disminuir un parámetro sin que cambie la base óptima actual.

Se utilizan para determinar el intervalo dentro del cual la solución sigue siendo válida bajo las condiciones del análisis.

Ejemplo:

Si un coeficiente de ganancia es 5, el aumento permisible es 2 y la disminución permisible es 3:

Limite inferior = 5 – 3 = 2

Limite Superior = 5 + 2 = 7

Por lo tanto, el intervalo es:

Dentro de ese intervalo, la base óptima se mantiene, aunque el valor de la función objetivo puede cambiar.

PRACTICA.

Ejercicio 1. Construcción del problema dual

Problema primal:

Max Z = 5X1 + 4X2

Sujeto a:

6X1 + 4X2 <= 24

X1 + 2X2 <= 6

-X1 + X2 <= 1

X1, X2 >= 0

Paso 1. El primal tiene 3 restricciones, por eso el dual tendrá 3 variables: Y1, Y2 y Y3.

Paso 2. Como el primal es de maximización, el dual será de minimización.

Paso 3. Los términos independientes (24, 6 y 1) pasan a la función objetivo dual.

Problema dual:

Min W = 24Y1 + 6Y2 + Y3

Sujeto a:

6Y1 + Y2 - Y3 >= 5

4Y1 + 2Y2 + Y3 >= 4

Y1, Y2, Y3 >= 0

Ejercicio 2. Comprobar la solución óptima

Solución del primal: X1 = 3 y X2 = 1.5.

Z = 5(3) + 4(1.5) = 15 + 6 = 21.

Ganancia máxima: Z = 21.

Para el dual, por holgura complementaria: Y3 = 0.

Como X1 y X2 son positivos, las restricciones duales se igualan:

6Y1 + Y2 = 5

4Y1 + 2Y2 = 4

Resolviendo: Y1 = 0.75, Y2 = 0.5 y Y3 = 0.

W = 24(0.75) + 6(0.5) + 0 = 18 + 3 = 21.

Comprobación: Z = W = 21.

Ejercicio 3. Análisis de sensibilidad

Precio sombra del recurso 1: 0.75.

Si se agregan 2 unidades del recurso 1:

Cambio en Z = 0.75 x 2 = 1.50.

Nueva ganancia = 21 + 1.50 = 22.50.

Precio sombra del recurso 2: 0.50.

Si se agregan 2 unidades del recurso 2:

Cambio en Z = 0.50 x 2 = 1.

Nueva ganancia = 21 + 1 = 22.

Ejercicio 4. Cambio en la ganancia de un producto

La ganancia de X2 baja de Q4 a Q3.

Con la solución anterior (X1 = 3, X2 = 1.5):

Z = 5(3) + 3(1.5) = 15 + 4.5 = 19.50.

Pero la solución óptima cambia. La nueva solución es X1 = 4 y X2 = 0.

Nuevo valor: Z = 5(4) + 3(0) = 20.
