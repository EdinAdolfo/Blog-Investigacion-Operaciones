¿Qué es la formulación de modelos?

La formulación de modelos consiste en traducir una situación real a un modelo matemático. En Investigación de Operaciones, permite estudiar distintas alternativas y elegir la decisión más conveniente cuando los recursos o las condiciones son limitados.

En Programación Lineal, el modelo normalmente pretende maximizar un beneficio o minimizar un costo mediante relaciones matemáticas lineales.

Elementos de un modelo de Programación Lineal.

Un modelo de Programación Lineal se integra, principalmente, por los elementos siguientes:

Variables de decisión

Son las cantidades que se deben determinar para solucionar el problema.

Por ejemplo, cuando una empresa produce dos artículos:

X1 = cantidad del producto 1

X2 = cantidad del producto 2

Las variables expresan las decisiones que la empresa debe tomar.

Función objetivo

Representa aquello que se pretende maximizar o minimizar.

Por ejemplo, si cada producto produce cierta ganancia:

Max Z = 30X1 + 40X2

La función expresa que se busca alcanzar la mayor ganancia posible.

También puede ser un caso de minimización, por ejemplo, si se pretende disminuir costos.

Restricciones

Son las limitaciones o condiciones que la solución debe cumplir.

Por ejemplo, si solo se dispone de 100 kg de materia prima:

2X1 + 3Y2 <= 100

La restricción señala que el uso de materia prima no puede exceder los 100 kg disponibles.

Condiciones de no negatividad

Por lo general, las variables de decisión deben ser mayores o iguales que cero:

X1,X2 >= 0

Con esto se evitan soluciones que impliquen cantidades negativas de productos, recursos, trabajadores, etc.

¿Cómo se formula un modelo?

Para construir correctamente un modelo pueden seguirse los pasos siguientes:

Comprender el problema.
Reconocer la situación que se desea resolver y la información que proporciona.

Identificar las variables de decisión.
Definir las cantidades que se necesitan conocer.

Identificar el objetivo.
Precisar qué se busca maximizar o minimizar.

Identificar las restricciones.
Determinar qué recursos, condiciones o límites influyen en el problema.

Expresar matemáticamente las restricciones.
Transformar la información del problema en ecuaciones o desigualdades.

Definir las condiciones de no negatividad.

Redactar el modelo completo.

Ejemplo de formulación

Una empresa produce dos clases de escritorios: Estándar y Ejecutivo.

Cada escritorio Estándar aporta Q50 de utilidad y requiere 1 hora de ensamblaje y 3 horas de acabado.

Cada escritorio Ejecutivo aporta Q80 de utilidad y necesita 2 horas de ensamblaje y 2 horas de acabado.

Por semana, la empresa cuenta con 60 horas de ensamblaje y 120 horas de acabado.

Paso 1: Variables

X1 = cantidad de escritorios Estándar

X2 = cantidad de escritorios Estándar

Paso 2: Función objetivo

Dado que se desea maximizar la utilidad:

Max Z = 50X1 + 80X2

Paso 3: Restricción de ensamblaje

Cada escritorio Estándar requiere 1 hora y cada Ejecutivo requiere 2 horas:

X1 + 2X2 <= 60

Paso 4: Restricción de acabado

Cada escritorio Estándar requiere 3 horas y cada Ejecutivo requiere 2 horas:

3X1 + 2X2 <= 120

Paso 5: No negatividad

X1,X2 >= 0

Modelo completo

Max Z = 50X1 + 80X2

Sujeto a:

X1 + 2X2 <= 60

3X1 + 2X2 <= 120

X1,X2 >= 0

Este modelo traduce matemáticamente el problema de producción. La formulación concluye en este punto; después, puede resolverse con métodos como el Método Gráfico o el Método Simplex, los cuales se desarrollarán en las secciones siguientes del proyecto.
